# TaskFlow ✅

A beautiful, modern to-do list application with a premium dark theme and glassmorphism effects. TaskFlow helps you organize your tasks efficiently with an intuitive and visually stunning interface.

![TaskFlow](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features

- **Modern UI Design**: Premium dark theme with glassmorphism effects and smooth animations
- **Task Management**: Create, edit, complete, and delete tasks with ease
- **Smart Filtering**: View all tasks, active tasks, or completed tasks
- **Statistics Dashboard**: Track your productivity with real-time task statistics
- **Local Storage**: Your tasks are automatically saved and persist across sessions
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices
- **Keyboard Shortcuts**: Press Enter to quickly add tasks
- **Clear Completed**: Remove all completed tasks with one click

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/shivankushsingh09/TaskFlow.git
```

2. Navigate to the project directory:
```bash
cd TaskFlow
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

4. Visit `http://localhost:8000` in your browser

### Usage

1. **Add a Task**: Type your task in the input field and click the "+" button or press Enter
2. **Complete a Task**: Click the checkbox next to a task to mark it as complete
3. **Edit a Task**: Click the edit icon to modify an existing task
4. **Delete a Task**: Click the trash icon to remove a task
5. **Filter Tasks**: Use the filter tabs (All, Active, Completed) to view different task lists
6. **Clear Completed**: Click "Clear Completed" to remove all finished tasks
