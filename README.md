# TaskFlow

TaskFlow is a sleek, modern, and responsive To-Do List application. It helps you stay organized and manage your daily tasks with ease.

## Features

- **Modern UI**: Built with Bootstrap 5 and custom CSS for a premium feel.
- **Task Management**: Add, complete, and delete tasks seamlessly.
- **Persistence**: Your tasks are saved locally using `localStorage`, so they stay even if you refresh the page.
- **Search & Filter**: Quickly find specific tasks.
- **Responsive Design**: Works perfectly on desktops, tablets, and mobile devices.

## Getting Started

1. Clone the repository.
2. Open `index.html` in your favorite web browser.
3. Start managing your tasks!

## Technologies Used

- HTML5
- CSS3 (Custom & Bootstrap 5)
- JavaScript (Vanilla)
