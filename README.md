# TaskFlow

TaskFlow is a premium, modern To-Do List application designed to stay organized with style. Built with simplicity and aesthetics in mind, it features a glassmorphism design, smooth animations, and persistent local storage.

## Features

-   **Premium UI**: Glassmorphism effects, modern gradients, and polished typography.
-   **Task Management**: Add, edit, delete, and mark tasks as completed.
-   **Filtering**: Easily view All, Active, or Completed tasks.
-   **Data Persistence**: Tasks are saved to your browser's Local Storage, so you never lose your list.
-   **Responsive**: Works perfectly on desktop and mobile devices.

## Technologies Used

-   **HTML5**
-   **CSS3** (Bootstrap 5 + Custom animations & Glassmorphism)
-   **JavaScript** (ES6+)
-   **Google Fonts** (Outfit)
-   **FontAwesome** (Icons)

## How to Run

1.  Clone or download this repository.
2.  Open `index.html` in your favorite web browser.
3.  Start organizing your life!
