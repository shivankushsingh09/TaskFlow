# TaskFlow

TaskFlow is a premium, modern, and intuitive To-Do List application designed to help you organize your daily tasks with style. Built with a focus on aesthetics and user experience.

## Features

- **Premium UI/UX**: A sleek, modern design with smooth animations and a curated color palette.
- **Task Management**: Easily add, complete, and delete tasks.
- **Data Persistence**: Your tasks are saved automatically using LocalStorage, so you never lose your progress.
- **Filtering**: View All, Active, or Completed tasks to stay focused.
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices.

## Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS with modern features (Variables, Flexbox, Grid).
- **JavaScript**: Pure ES6+ for logic and state management.

## Getting Started

1. Clone the repository.
2. Open `index.html` in your web browser.
3. Start managing your tasks!
