# TaskFlow

TaskFlow is a modern, sleek, and intuitive To-Do List application built for productivity. Organize your daily tasks with ease using a beautiful interface.

## ✨ Features

- **Modern UI**: Clean and responsive design with high-quality aesthetics.
- **Task Management**: Add, complete, and delete tasks seamlessly.
- **Filtering**: View all tasks, or filter by active and completed status.
- **Persistence**: Your tasks are saved locally on your device using LocalStorage.
- **Responsive**: Works perfectly on both desktop and mobile devices.

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser!

## 🛠️ Built With

- **HTML5** & **Vanilla JavaScript**
- **CSS3** (Custom styling with modern techniques)
- **Bootstrap 5** (For layout and components)
