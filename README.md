# TaskFlow ✨

A beautiful, modern, and feature-rich To-Do List application built with pure HTML, CSS, and JavaScript. TaskFlow helps you organize your tasks with style, offering a premium user experience with smooth animations and a stunning dark-mode design.

## ✨ Features

- **🎨 Premium Design**: Modern glassmorphism UI with vibrant gradients and dark mode aesthetics
- **✅ Task Management**: Create, edit, complete, and delete tasks effortlessly
- **🏷️ Priority Levels**: Organize tasks with High, Medium, and Low priority badges
- **📁 Categories**: Group tasks with custom categories/tags
- **📅 Due Dates**: Set and track task deadlines
- **🔍 Smart Filtering**: Filter tasks by status (All, Active, Completed) and search by text
- **📊 Statistics**: Real-time task statistics and progress tracking
- **💾 Auto-Save**: LocalStorage integration for persistent data
- **📱 Responsive Design**: Seamless experience across all devices
- **⚡ Smooth Animations**: Delightful micro-animations for enhanced UX
- **🌙 Dark Mode**: Eye-friendly dark theme built-in

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/TaskFlow.git
```

2. Navigate to the project directory:
```bash
cd TaskFlow
```

3. Open `index.html` in your browser:
   - Simply double-click the `index.html` file, or
   - Use a local server (recommended):
   ```bash
   # With Python
   python -m http.server 8000
   
   # With Node.js
   npx serve
   ```

4. Start organizing your tasks! 🎉

### Usage

1. **Add a Task**: Type your task in the input field and press Enter or click the "+" button
2. **Complete a Task**: Click the checkbox to mark tasks as complete
3. **Delete a Task**: Click the delete (×) button to remove a task
4. **Filter Tasks**: Use the filter buttons (All, Active, Completed) to view specific tasks
5. **Search Tasks**: Use the search bar to find tasks quickly
6. **Set Priority**: Assign priority levels to your tasks for better organization
7. **Add Categories**: Tag tasks with categories for easy grouping

## 🎯 Key Features Explained

### LocalStorage Persistence
All your tasks are automatically saved to your browser's LocalStorage, ensuring your data persists even after closing the browser.

### Priority System
- **High**: Red badge for urgent tasks
- **Medium**: Orange badge for important tasks
- **Low**: Blue badge for regular tasks

### Smart Filtering
- **All**: View all tasks
- **Active**: Show only incomplete tasks
- **Completed**: Display finished tasks
